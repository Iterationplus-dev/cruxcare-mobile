Financial disclosure

The non-negotiable pattern: no money action is confirmable until the server has returned the exact amount, the fee, the lock or notice period, and the resulting balance. Never an optimistic success.

Accessibility checklist
check_circleBody text ≥4.5:1; large text and icons ≥3:1
check_circleLeaf #2FA36B and amber #C9772E are for icons, fills and ≥19px text only
check_circleText under 19px uses the darker pair: amber #8A4E17 (6.6:1), leaf #1F6E42 (6.2:1)
check_circleink/400 #61706A is cleared for white, surface/1 and mist — not for amber or leaf tints
check_circleMuted tints #9BD2C8 / #B9DED6 / #CDE7E1 are cleared on #0A5A4E only; on #0E7C6B use #FFFFFF or #F2F7F5
check_circleTargets ≥44×44 with ≥8px separation
check_circleAmounts read as words: "two thousand four hundred eighty dollars"
check_circleStatus changes announced via live regions
check_circleFocus ring: 3px #9BD2C8, 2px offset, never removed
check_circleEvery icon-only control carries an accessible label
check_circleErrors reference the field by name, in plain language
